# 操作与变更控制

## 动作前门

任何写入、命令或外部动作前确认：

- 目标绝对路径、活动副本和操作对象已解析。
- 动作在用户授权和任务范围内。
- 备份已做，路径已记下。
- 必须保留的数据、原生历史、密钥和人工内容已从删除/覆盖集合排除。
- 直接消费者与反向引用已纳入设计。
- 失败时能停止在哪里，怎样判断部分完成。
- 回退强度与风险相称。

## 备份铁律

- 任何会改文件的任务，动手前只为明确要修改、删除或覆盖的文件保留回退内容，存入 `{{BACKUP_ROOT}}/<类别>/<项目或对象>-<事件>前-<yyyyMMdd-HHmmss>/`。类别现行用 `python`（代码与项目）和 `system`（规则、配置、文档）。
- 无论任务大小，都按实际改动文件保存：修改/删除的文件保留改前内容或可验证的逆向补丁；新增文件只记录路径，回退时删除本轮新增且未再被修改的文件。清单记录原路径、改动原因、增删改类型、改前/改后哈希及恢复方法，不能只记一句“改过代码”而没有可恢复内容。
- 不因中/大任务、测试或打包而复制整个项目、规则库、依赖目录、旧更新包或运行数据。未改文件不备份，EXE/依赖等可重建产物不重复存整份；确需覆盖发布时，仅保留实际替换/删除文件的旧内容，已有更新器差异回退可直接复用。只有用户明确要求完整快照时才整份备份。
- 同一任务同一文件的相同旧版本只保存一次；后续阶段记录增量，扩展到新文件时在修改前补入。不同任务目录不覆盖；回退前核对当前文件版本，发现用户或其他任务的新改动先报告冲突，不覆盖。
- 备份路径写进项目变更记录和最终答复。用户明确说「不用备份」时可以不备，但仍要核对目标和保留边界。
- 本规则库自身也只保存受改文件的旧内容，改后在 [变更记录.md](../变更记录.md) 记一条。本库不使用 git。此规则只改变后续备份行为，历史备份的删除/压缩须另有用户授权。

## 回退策略

优先级从轻到重：

1. 从备份目录把原文件覆盖回去，或恢复配置原值。
2. 受影响文件的动作前快照。
3. 中/大任务的阶段改动清单与增量回退内容，不扩大成全项目快照。
4. 不可逆外部动作必须在执行前取得明确授权，并先做预演或意图清单。

## 删除、覆盖与移动

- 用户的文件（代码、模板、xlsx、原票、正式输出、规则、记忆、原生历史）不直接永久删除：挪到项目 `_回收站/<日期>_<事件>/` 或 code_back 备份目录，并报告位置。`rm`、`Remove-Item` 这类直接永久删除只用于自己本轮生成的临时产物和缓存。
- 使用绝对且已验证的目标；禁止对盘符根、用户目录根、工作区根或未解析变量做递归破坏。
- 先枚举精确集合，再执行，再复扫。
- 只因文本中出现某个词，不足以删除整个文件；先判断该文件是不是用户数据、原生历史或业务资产。
- 删除物质性内容后报告范围和可恢复性。

## 范围纪律

- 用户指定的对象就是全部范围：说改采集表就不碰副采集表，说改一张票就不碰同系列其他票，说查就不改。
- 关联问题、顺手修复、推断扩改都算新范围：动手前列出拟改对象、内容、原因，取得同意；未获同意只报告。获准后在最终答复里逐项说明实际改了什么。
- 改完同时验证目标区域和非目标区域，证明没有连带改变。

## 数据与文件纪律

- 数据不合格就报错停下，不写默认值、不猜：采集表缺字段、单价为 0、数量为 0、名称超长、必填为空，都让用户去修。
- 用户手工改过的文件或数据是最终决定，不拿原票、旧版本或「更合理」去否决。
- 用户说「数据更新了」「重新生成」时重读源文件，不用缓存；公式列用只读值方式读到空时，要重算或提示，不能当 0。
- 临时脚本、诊断脚本、测试产物放项目约定的测试目录（默认 `_测试/<日期>_<任务>/`），用中文名，不放桌面、不混进正式目录；测试脚本不得冒充正式出票入口。
- 涉及真实个人信息或用户标记为保密的数据目录，只跑脚本报聚合数字，不读取、不展示内容。
- 不主动打包 exe；用户明确说「打包」才打，产物放 `{{GLOBAL_RULES_ROOT}}/code_pack/<类别>/<项目>/`。默认源码直接运行验证。

## PDF 与文档导出禁止调用打印驱动

生成、导出、转换、渲染或预览 PDF 时，以下规则为全局硬约束：

- 禁止调用物理打印机、虚拟 PDF 打印机、系统打印后台程序、打印机驱动或任何以打印队列为中介的链路。
- 禁止使用 `PrintOut`、「Microsoft Print to PDF」及会初始化或依赖打印机/打印驱动的 Office/COM `PageSetup`、`ExportAsFixedFormat` 等路径。
- 只能使用不经过系统打印子系统的直接路径，例如直接写 PDF 的库、应用明确声明的无打印驱动导出接口、浏览器直接 PDF 协议或无打印驱动的 headless 转换器。
- 动作前必须确认所选路径不访问打印驱动或打印队列；不确定时按禁止处理，不得试调用后再判断。
- 直接 PDF 路径不可用时，改用结构检查、直接图片/HTML 预览或报告当前限制；禁止自动选择、安装或回退到任何打印机/虚拟打印机。
- 验证进程异常时只终止本任务自己启动且已核实身份的进程，不影响用户已有的 Office 或打印会话。

## 配置与共享契约

修改入口、Schema、公共规则或共享工具时，最低按中任务：检查所有已知消费者、兼容路径、安装/升级/卸载和回退。配置剥离应保留用户自定义字段，优先使用提供方的受管卸载机制。

## 运行环境默认

- Python：优先使用项目明确指定的 Python 版本；未指定时使用当前环境可用的 Python，并在运行前核验版本。
- 编码：UTF-8；Windows 上读写文件显式指定编码；控制台输出考虑 GBK 环境。
- 项目根目录的公共能力（如 `PublicCodeUtils.py`、`InvoiceUtils.py`）默认只读依赖；要改必须按中任务走跨项目回归。

## 执行纪律

修改权威源，不手工维护多个副本；机械同步必须有完整性校验。命令输出只能证明该命令发生过，不能代替对交付物和消费者的验证。

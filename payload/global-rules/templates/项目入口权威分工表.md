# 项目入口权威分工表

放进项目根 `CLAUDE.md`，条款见 [memory/04 · 项目接入契约](../memory/04_权威状态与会话.md#项目接入契约)。每行只填一个唯一位置。

| 信息 | 唯一权威位置 |
| --- | --- |
| 项目入口、读取顺序和高频禁令 | `CLAUDE.md` |
| 当前任务、依赖、状态和待办 | |
| 现行制作、采集、三表、出票和质检规则 | `规则.md` → `_规则/` |
| 单店、单票、单版本事实 | 该票自己的 `_规则/` |
| 跨会话项目认知与禁止恢复项 | |
| 项目变更记录 | |
| 回退点 | `{{BACKUP_ROOT}}/<类别>/<项目>-<事件>前-<时间戳>/` |
| 临时 PDF、PNG、JSON、日志和一次性脚本 | `_测试/<日期>_<任务>/` |
| 废弃项目版本及其整套资产 | `_回收站/<日期>_<事件>/` |
| 正式输出 | |
| 根共享能力（只读依赖） | |

冲突时依次服从：平台系统/开发者指令 → 用户当轮明确指令 → 用户确认的手工修改 → 当前原票、当前官网证据和当前代码 → 当前票自己的 `_规则` → 根 `_规则` → 记忆摘要 → 历史归档与备份。
